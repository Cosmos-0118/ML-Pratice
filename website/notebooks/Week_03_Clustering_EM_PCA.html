Practice tasks covered

  1. K-means, Gaussian mixtures and hierarchical clustering to group days into weather types

Practice 1 — Clustering¶

K-means from scratch¶

Repeat two steps until nothing changes: (1) give every day to its nearest centre, (2) move each centre to the mean of its days.

In [2]:
def kmeans(Z, k, seed=0, steps=100):
    rng = np.random.default_rng(seed)
    centres = Z[rng.choice(len(Z), k, replace=False)]
    for _ in range(steps):
        dist = ((Z[:, None, :] - centres[None]) ** 2).sum(-1)       # distance of every day to every centre
        labels = dist.argmin(1)                                      # step 1: nearest centre
        new = np.array([Z[labels == j].mean(0) if (labels == j).any() else centres[j] for j in range(k)])
        if np.allclose(new, centres): break
        centres = new                                                # step 2: move the centres
    return labels, centres, dist.min(1).sum()

# k-means can get stuck in a poor solution, so try 10 starting points and keep the best
labels, centres, inertia = min((kmeans(Z, 4, seed=s) for s in range(10)), key=lambda r: r[2])
sk = KMeans(4, n_init=10, random_state=0).fit(Z)
print("agreement with scikit-learn (1 = identical grouping):", round(adjusted_rand_score(labels, sk.labels_), 3))

agreement with scikit-learn (1 = identical grouping): 0.996

Mixtures of Gaussians and EM from scratch¶

K-means gives every day to exactly one cluster. A Gaussian mixture says "this day is 80% cluster A, 20% cluster B". EM alternates: E-step, compute each day's membership probabilities; M-step, re-estimate each cluster from the weighted days.

In [4]:
def gmm_em(Z, k, steps=200, seed=0):
    n, dim = Z.shape
    rng = np.random.default_rng(seed)
    mu = Z[rng.choice(n, k, replace=False)]
    var = np.ones((k, dim)); pi = np.full(k, 1 / k)                  # diagonal covariances keep the code short
    for _ in range(steps):
        # E-step: responsibility of every cluster for every day
        logp = -0.5 * (((Z[:, None] - mu) ** 2 / var).sum(-1) + np.log(var).sum(-1)) + np.log(pi)
        logp -= logp.max(1, keepdims=True)
        r = np.exp(logp); r /= r.sum(1, keepdims=True)
        # M-step: weighted means, variances and cluster sizes
        nk = r.sum(0)
        mu = (r.T @ Z) / nk[:, None]
        var = (r.T @ Z ** 2) / nk[:, None] - mu ** 2 + 1e-6
        pi = nk / n
    return r, mu, var, pi

r, mu, var, pi = gmm_em(Z, 4)
em_labels = r.argmax(1)
print("cluster sizes:", np.bincount(em_labels), "| mixing weights:", pi.round(2))
print("share of days that are clearly in one cluster (> 90%):", round((r.max(1) > .9).mean(), 2))

Choosing the number of mixture components with BIC¶

BIC rewards a good fit but charges for every extra parameter; lower is better. (scikit-learn's mixture here uses full covariances, a little more flexible than the diagonal ones above, so the two will not match exactly.)

Hierarchical clustering¶

Start with every day on its own and repeatedly merge the two closest groups (Ward's rule). Cut the tree to get clusters.

In [6]:
tree = linkage(Z, method="ward")
hier_labels = fcluster(tree, 4, criterion="maxclust") - 1
plt.figure(figsize=(8, 3)); dendrogram(tree, truncate_mode="lastp", p=20, no_labels=True); plt.title("hierarchical clustering (last 20 merges)")

Do the three methods agree, and are the groups meaningful?¶

adjusted_rand_score is 1 for identical groupings and about 0 for unrelated ones. Only the two mixture models (0.83) agree strongly; the other pairs agree only partly (0.3–0.5), which is normal when the data has no sharp groups.

Practice 2 — Principal component analysis (PCA)¶

PCA finds new axes (principal components) along which the data varies most, so a few numbers can stand in for four.

Summary¶

  • The clusters are readable (warm and dry, mild and rainy, ...) and match the labelled weather types they never saw. But the three methods only partly agree and no number of clusters stands out (silhouette 0.37, BIC keeps falling): weather changes gradually.
  • EM is the same idea as k-means with soft membership; both were written here in about 15 lines.
  • Two principal components (warm/dry/calm vs cool/wet, and wind/rain) keep 82% of the variation of the four columns.
